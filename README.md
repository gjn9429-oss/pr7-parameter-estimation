## Блоки роботи

- `src/block1.py` – MoM та MLE для Exp(0,04), по 1000 вибірок для дев’яти обсягів; Bias і MSE.
- `src/block2.py` – синтетична нормальна вибірка обсягу 50 з параметрами 142,5 мс і 18,2 мс; інтервали для μ, σ² та σ.
- `src/block3.py` – інтервали Волда й Вілсона для 35 помилок у 500 запитах, ширина інтервалу та потрібний обсяг.
- `src/block4.py` – довірчий інтервал середньої затримки та перевірка SLA 100 мс.

Результати виводяться в термінал, два графіки зберігаються в `graphics/` без відкриття вікон.
Звіт: [PDF](report/PR13_14_Report_Rymarenko.pdf).

У блоках 1 і 2 використано незалежні генератори із зернами 42 і 43.
Параметри генерації блока 2 не підміняють оцінки, отримані з вибірки.
Інтервал Вілсона є наближеним score-інтервалом: слово «точний» у методичці некоректне.
Потрібний n у блоці 3 – планування за фіксованою часткою 0,07 та формулою Волда.
SLA у блоці 4 перевіряється для середнього, а не для кожного окремого запиту.
